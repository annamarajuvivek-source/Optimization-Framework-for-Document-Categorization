DSA Toolkit

The main data structures and algorithms used in the project concept.

HM

HashMap

Maps categories and keywords for fast key-value lookup and category matching.

TR

Trie

Supports efficient prefix and keyword searching through character-based paths.

PQ

Priority Queue

Ranks category candidates and selects the highest-scoring category.

SO

Sorting

Organizes documents or search results according to relevance and score.

SC

Category Scoring

Counts matching keywords and converts the strongest match into a confidence score.

SR

Search & Retrieval

Returns analyzed documents matching the user's search term or category.
