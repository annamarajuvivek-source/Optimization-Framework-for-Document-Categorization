OPTIMIZATION FRAMEWORK FOR DOCUMENT CATEGORIZATION

Project structure:
- index.html          Main website structure
- css/style.css       All website styling
- js/script.js        Document analyzer, categorization and search logic

How to run:
1. Open this folder in VS Code.
2. Open index.html.
3. Right-click index.html -> Open with Live Server.
4. Upload a .txt file or paste document text and click Analyze & Categorize.

Note:
This is a frontend prototype. The categorization logic currently runs in JavaScript in the browser.
